# Arcaneland

Arcaneland is a 2D top-down roguelike that has been developed as a university Final Degree Project (TFG).
Non-commercial / educational project.

## Download
- Play the latest build on itch.io: (pon aquí tu enlace)

## Controls
- Movement: WASD
- Shooting: Arrow Keys
- Strong attack: Space
- Interact: E
- Map: M
- Exit: Esc

## Tech
- Engine: Unity (pon versión exacta, ej: 2022.3.x LTS)
- Platform: Windows (x64)
